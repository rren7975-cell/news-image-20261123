# 23 November World News in One Image

Entry for the make.fun bounty "Sum up 23 November's world news in one image".

A 1024x1024 newspaper front page (entry.png) summarising the world news of Monday 23 November 2026: 3 lead stories, 10 briefs and a 5-item "Also" strip.

## Run

python3 main.py  (Python 3.13, standard library only) — copies entry.png to /output/entry.png.
